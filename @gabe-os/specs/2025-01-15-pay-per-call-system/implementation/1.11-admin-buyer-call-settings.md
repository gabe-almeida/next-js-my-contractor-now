## Key Implementation Decisions

### 1. JSON Structure for Hours of Operation

Stored in `callHoursOfOperation` column:
```json
{
  "timezone": "America/New_York",
  "hours": {
    "monday": { "active": true, "start": "08:00", "end": "18:00" },
    ...
  },
  "requireIvrQualification": true,
  "acceptWithoutCallerId": false,
  "allowCascade": true
}
```

**Rationale:** Keeps related settings together, allows easy extension for future fields.

### 2. Phone Number Normalization

All phone numbers are normalized to E.164 format (+1XXXXXXXXXX) on save.

**Rationale:** Twilio requires E.164 format for call routing. Accepting various input formats improves UX.

### 3. Shared Call Settings Across Services

Call bid settings are applied to ALL service configs for a buyer.

**Rationale:** Simplifies initial implementation. Can be made per-service later if needed.

### 4. Bid Validation Range

Bids must be between $5 and $500.

**Rationale:** Matches existing lead bid constraints in the system.
