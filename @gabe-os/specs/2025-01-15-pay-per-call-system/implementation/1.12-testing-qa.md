
## Testing Patterns Used

1. **Arrange-Act-Assert**: All tests follow this structure
2. **Mock Isolation**: Each test resets mocks in beforeEach
3. **Factory Functions**: Reusable test data generators
4. **Error Scenario Coverage**: Both happy path and failure paths tested
5. **Idempotency Testing**: Duplicate webhook handling verified
6. **State Machine Testing**: Valid and invalid transitions tested

## Running Tests

```bash
# Run all call-related tests
npm test -- --testPathPattern="calls"

# Run specific test file
npm test -- src/lib/auction/__tests__/call-engine.test.ts

# Run with coverage

npx tsx scripts/load-test-calls.ts --concurrent 5 --duration 30
```
