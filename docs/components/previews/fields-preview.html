Smart Fields System

Single source of truth for all form inputs across the application.

Import from: @/components/ui/fields

TextInput

For single-line text fields with optional auto-formatting.

Standard Text Input
<TextInput value={name} onChange={setName} label="Full Name" />
Name Field with Auto-Capitalize

nameOnly: letters, spaces, hyphens, apostrophes only

capitalizeWords: auto-capitalizes first letter of each word

<TextInput value={firstName} onChange={setFirstName} label="First Name" required nameOnly capitalizeWords />
Password Field
<TextInput type="password" value={password} onChange={setPassword} label="Password" icon={<Lock />} />
With Icon (Left)
<TextInput type="url" value={website} onChange={setWebsite} label="Website" icon={<Globe />} />
EmailInput (Smart Field)

Auto-validates email format, removes ALL spaces, normalizes to lowercase on blur.

Standard Email Input

Built-in behaviors:

  • • Spaces are completely blocked (removed while typing)
  • • Normalizes to lowercase on blur
  • • Validates format: requires @, domain with period, 2+ char TLD
<EmailInput value={email} onChange={setEmail} label="Email" required icon={<Mail />} />
Validation Error State

Domain must include a period (e.g., .com)

Valid State (with showValidation)
<EmailInput value={email} onChange={setEmail} showValidation />
PhoneInput (Smart Field)

Auto-formats US phone numbers as (555) 123-4567. Only allows digits.

Standard Phone Input

Built-in behaviors:

  • • Auto-formats as you type: 5551234567 → (555) 123-4567
  • • Only allows digit input
  • • Returns clean digits (5551234567) to onChange
  • • Validates 10-digit US phone numbers
<PhoneInput value={phone} onChange={setPhone} label="Phone" required icon={<Phone />} />
Valid State (10 digits)
<PhoneInput value={phone} onChange={setPhone} showValidation />
